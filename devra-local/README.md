# Devra — سیستەمی ناوخۆیی مینیو و کاشێر (بەبێ پێویستی بە ئینتەرنێت)

ئەم سیستەمە لەسەر کۆمپیوتەر/لاپتۆپی کاشێر کاردەکات و لە ڕێگەی وایفایی ناوخۆیی (Local WiFi)
کڕیار پەیوەندی پێوە دەکات — هیچ پێویستی بە ئینتەرنێتی ڕاستەقینە نییە.

## پێداویستی (یەکجار دایبمەزرێنە)

1. [Node.js](https://nodejs.org) دابمەزرێنە لەسەر کۆمپیوتەری کاشێر (وەشانی LTS).
2. ئەم فۆڵدەرە بکۆپی بکە بۆ سەر کۆمپیوتەرەکە.
3. تێرمینال/CMD بکەرەوە لەناو فۆڵدەرەکەدا و بنووسە:
   ```
   npm install
   ```
   (ئەمە تەنها یەکجار پێویستە، پێویستی بە ئینتەرنێتە تەنها بۆ ئەم هەنگاوە).

## هەر ڕۆژێک، دەستپێکردنی سیستەمەکە

1. کۆمپیوتەری کاشێر بکە بە وایفای/هۆتسپۆتی خۆی (ڕاوتەری کافێکە، پێویست بە ئینتەرنێت ناکات).
2. لەناو فۆڵدەرەکەدا بنووسە:
   ```
   npm start
   ```
3. لە تێرمینالەکەدا چەند ناونیشانی IP دەردەکەون، نموونە:
   ```
   ئەم ئامێرە لەسەر تۆڕی ناوخۆیی: http://192.168.1.5:3000
   ```
   ئەم ژمارەیە تۆمار بکە.

## دروستکردنی کوارکۆدی مێزەکان (یەکجار)

1. لە وێبگەڕی کۆمپیوتەرەکەدا بچۆ بۆ: `http://localhost:3000/qr.html`
2. IPـی سەرەوە (نموونە `192.168.1.5`) بنووسە و ژمارەی مێزەکان دیاری بکە.
3. "دروستکردن" بکە، پاشان "چاپکردن" — کوارکۆدەکان چاپ بکە و لەسەر هەر مێزێک دایبنێ.

## بەکارهێنان

- **کڕیار**: مۆبایلەکەی دەبەستێتەوە بە وایفایی کافێکە، کوارکۆدی سەر مێزەکەی سکان دەکات، مینیو دەکرێتەوە، داواکاری دەنێرێت.
- **کاشێر**: لەسەر هەمان کۆمپیوتەر بچۆ بۆ `http://localhost:3000/pos.html` — داواکارییەکان ڕاستەوخۆ دەردەکەون.

## تێبینی گرنگ

- هەموو ئامێرەکان (کۆمپیوتەری کاشێر و مۆبایلی کڕیار) پێویستە لە **یەک وایفایدا** بن.
- داتای داواکارییەکان لە فایلی `orders.json` هەڵدەگیرێت لەناو هەمان فۆڵدەر — ئەگەر کۆمپیوتەرەکە داخرا و دووبارە کرایەوە، داتاکان دەمێننەوە.
- بۆ گۆڕینی مینیو/نرخەکان، فایلی `public/index.html` بکەرەوە و بەشی `MENU` بگۆڕە.
- بۆ ڕاگرتنی سیستەمەکە: لە تێرمینالەکەدا `Ctrl + C` دابگرە.
